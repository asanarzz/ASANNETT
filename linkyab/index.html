استخراج لینک‌های دانلود

آدرس صفحه رو وارد کن و «استخراج» رو بزن. این صفحه سعی می‌کنه HTML اون آدرس رو (از طریق یک پراکسی عمومی، چون مرورگر مستقیم به خاطر CORS اجازه نمی‌ده) بخونه و لینک‌هایی که به دانلود شبیه‌ان رو لیست کنه. اگه سایت مقصد جلوی خزیدن (scraping) رو گرفته باشه یا محتوا با جاوااسکریپت ساخته بشه، ممکنه نتیجه‌ای پیدا نشه.

⚠️ پراکسی‌های عمومی زیر (allorigins، corsproxy و...) رایگان و از سرورهای شخص ثالث‌ان — گاهی کار می‌کنن گاهی نه، و هیچ تضمینی روشون نیست. برای نتیجه‌ی همیشه پایدار، یک پراکسی اختصاصی رایگان روی Cloudflare Workers بساز (راهنما پایین صفحه) و آدرسش رو اینجا بذار؛ همیشه اول همون امتحان می‌شه.

    هنوز چیزی پیدا نشده.
    نمایش HTML خام دریافتی (برای دیباگ)
    ✅ راهنما: ساخت پراکسی اختصاصی رایگان و همیشه‌کار (چند دقیقه، بدون کارت بانکی)
    1. برو به dash.cloudflare.com و با ایمیل یه حساب رایگان بساز.
    2. از منوی سمت چپ برو به «Workers & Pages» و روی «Create» بزن، بعد «Create Worker» رو انتخاب کن.
    3. یه اسم بهش بده (مثلا myproxy) و «Deploy» رو بزن.
    4. بعد از دیپلوی، روی «Edit code» بزن و کل کد پیش‌فرض رو پاک کن، به‌جاش این کد رو بچسبون:
    export default { async fetch(request) { const url = new URL(request.url); const target = url.searchParams.get('url'); if (!target) { return new Response('Missing url param', { status: 400 }); } try { const resp = await fetch(target, { headers: { 'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64)' } }); const body = await resp.arrayBuffer(); return new Response(body, { status: resp.status, headers: { 'Content-Type': resp.headers.get('Content-Type') || 'text/html; charset=utf-8', 'Access-Control-Allow-Origin': '*' } }); } catch (e) { return new Response('Fetch failed: ' + e.message, { status: 502 }); } } }
    1. روی «Deploy» یا «Save and deploy» بزن.
    2. آدرسی که بالای صفحه‌ی worker نشون داده می‌شه (چیزی شبیه https://myproxy.YOURNAME.workers.dev) رو کپی کن و توی فیلد «آدرس Worker اختصاصی خودت» بالای همین صفحه بچسبون.

    از این به بعد این آدرس ذخیره می‌مونه و همیشه اول همون امتحان می‌شه — چون این Worker مال خودته، هیچ‌کس دیگه‌ای نمی‌تونه کندش کنه یا محدودش کنه، و همیشه در دسترسه.
